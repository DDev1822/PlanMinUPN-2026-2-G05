# Aprende con Kai · Santa Elena G05

![DrillStone](../assets/L1.png)

Kai Planeamiento te acompaña a comprender los datos de Santa Elena y a interpretar sus modelos académicos. Tú observas, razonas y respondes; Kai explica, te orienta y conserva tu progreso.

## Comenzar

1. Abre el proyecto G05 en PyCharm.
2. Abre el chat de GitHub Copilot y selecciona el agente **Kai Planeamiento**.
3. Escribe «quiero empezar». Si es la primera vez, elige un alias que te permita retomar el recorrido. No necesitas dar tu nombre legal ni correo.
4. Lee la explicación, explora el visor cuando Kai te lo indique y responde con tus propias palabras. Puedes pedir una pista o una explicación más profunda.

Si regresas después, escribe «quiero continuar» y usa el mismo alias. Kai recuperará la actividad pendiente.

## Qué vas a estudiar

- **E1:** las observaciones geológicas, los compósitos y el modelo preliminar M01B.
- **S11:** qué representan las leyes, la densidad, el volumen y el tonelaje estimados, y dónde falta respaldo.
- **S12:** la clasificación académica de bloques y la comparación de escenarios A/B.

Las cifras que ya tiene el proyecto sirven para analizar y discutir su significado. Kai no necesita que copies cada número de la página para demostrar comprensión. La ficha del proyecto conserva los datos verificados y tus explicaciones se registran por separado.

## Cómo usar la página

En [la página del proyecto](../../index.html) puedes abrir los visores de sondajes y M01B. Para S11/S12, [explora los resultados y busca bloques](RESULTADOS_G05.html): cada tarjeta muestra el valor, su unidad y el modelo correspondiente; la cuadrícula permite localizar bloques vecinos. Desde allí puedes abrir el modelo 3D. Si una propiedad aparece sin estimación, esa ausencia también importa: pregunta qué soporte falta antes de sacar conclusiones. No necesitas abrir archivos de datos para responder a Kai.

Estos modelos son ejercicios de aula con datos sintéticos. No constituyen una declaración profesional de recursos o reservas minerales.
